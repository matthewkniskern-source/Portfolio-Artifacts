# Current Inventory Workflow

## Warehouse / Phone Order

Zoho Inventory
→ Clerk searches product / SKU
→ Confirms available quantity
→ Builds sales ticket manually
→ Order proceeds to fulfillment

## Website Inventory

Zoho Inventory
→ Manager reviews current stock
→ Website availability updated manually
→ Customer purchases through Lightspeed
→ Order arrives internally by email
→ Staff handles fulfillment manually
→ Inventory reconciliation occurs outside the web transaction

## Current Systems

**Zoho Inventory**

* Warehouse inventory tracking
* Inventory source used by staff
* Current stock confirmation for phone orders

**Lightspeed**

* Public ecommerce storefront
* Public retail pricing
* Cart
* Checkout
* Payment processing
* Completed online transaction record

## Current Manual Touchpoints

* Website stock availability update
* Online-order handoff to staff
* Internal fulfillment entry
* Inventory reconciliation
* Stock discrepancy review

## Current Gaps

* Duplicate inventory maintenance
* Website inventory can lag Zoho
* No automated cart reservation
* No automated Zoho decrement from completed web sale
* Manual order handoff
* Limited discrepancy traceability
* Potential oversell risk
* Out-of-stock products can become dead-end purchase paths
