# Representative User Journeys — Academic Browser Prototype

These journeys illustrate the client-side user interface. They are not records of production customer purchases.

## Product discovery and cart

**Visitor goal:** Locate an item and review a potential purchase.

1. Navigate from Home to Products and browse the fictional catalog.
2. Open a product page and inspect the item description.
3. Add a selected quantity to the browser-local cart.
4. Review the cart, adjust quantities and inspect the displayed subtotal.
5. Proceed to simulated checkout if continuing the demonstration.

**Limit:** Prices, availability and order processing are not linked to a production retailer.

## Store discovery

**Visitor goal:** Identify a fictional store location.

1. Open Locations.
2. Review store details and contact information.
3. Use the site navigation to return to product discovery.

**Limit:** Locations are demonstration records.

## Simulated checkout

**Visitor goal:** See the planned ordering experience.

1. Review the cart.
2. Enter only fictional customer/payment data in the academic interface.
3. Submit the demonstration form.
4. Review browser-local confirmation behavior.

**Limit:** No real payment, order acceptance, inventory decrement or fulfillment occurs.

## Unavailable item / special order

**Visitor goal:** Explore an alternative to a conventional purchase.

1. Review a product or navigate to Special Orders.
2. Follow the available inquiry flow.
3. Treat any request as a simulated customer-facing interaction unless its behavior is independently verified.
