# Security gates
Trivy configuration scan plus Python policy evaluator. Raw findings are not suppressed. The evaluator reports all findings and exact-scoped exceptions (kind, file, check, resource, severity). Unrelated high/critical and unknown severity findings block. Pending exceptions return exit 2; approved exceptions with valid review dates return exit 0 but never authorize deployment. Expired or invalid approvals do not waive a blocking finding. Tests use synthetic approvals only. The prototype relies on policy metadata; protected review and authenticated authorization are not implemented. Additional SAST, SCA, secrets and runtime enforcement are planned.
