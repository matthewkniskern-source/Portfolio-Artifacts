# Requirements workbench
Run from repository root: `python3 Enterprise-Security-Automation/governance/workbench.py` then open http://127.0.0.1:8765. Windows: use python instead of python3 if appropriate. No external packages. Local loopback only; do not expose to the Internet. No RBAC, authentication, database, or production use.
Use the form to propose contract requirements, choose scanner and severity, designate manual or undetermined applicability, then export proposal JSON. Import unified-decision.json from a completed run and explicitly select completed scanners. Imported evidence is unverified; CI-generated assessment uses the same engine and known successful scanner steps. Effective threshold is the stricter of applicable rules; exception permission intersects. Proposed non-applicability never means approved exclusion. Baseline rows cannot be disabled but imported profiles are not authenticated and may replace baseline content; therefore assessments are proposals only, not authoritative policy. No changes to actual CI policy, no approval and no certification. Manual requirements and missing evidence require review. No matching finding is not proof of compliance. Sample contract clauses are fictional; no actual NIST mapping asserted here.
Future: signed/versioned profile registry, authoritative baseline enforcement, evidence manifest verification, source/revision catalog, conflict workflow, owner authorization, RBAC, durable audit store, and deployment integration.
