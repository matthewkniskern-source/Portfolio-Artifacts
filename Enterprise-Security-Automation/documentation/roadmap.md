# Roadmap
1. Baseline source, static CI and unit tests.
2. Validate real CI runs; exercise negative fixtures and remediation; pin tool/action versions and review supply chain.
3. Add SAST, SCA and secret scanning; normalize scanner output.
4. Add requirements overlays, traceable control evidence, decision matrix and exception lifecycle.
5. Configure branch protection and independent human approvals; design AWS OIDC with least privilege and budget alerts before any deployment.
6. Build read-only dashboard, runtime verification and teardown.
7. Integrate reviewed legacy artifacts and eventual isolated Proxmox/OT target.
